# Identity Journey

Here you can find the Agama flows and assets related to the journey described [here](https://github.com/GluuFederation/private/wiki/Gluu-Cloud-Identity-Journeys). This folder can be seen as an exploded `.gama` archive.

To build the actual archive, download the agama inbound identity [jar](https://maven.jans.io/maven/io/jans/agama-inbound/) inside `lib`. Finally, compress the contents of folders `code`, `web`, `lib` including the file `project.json`.

Deployment instructions can be found [here](deployment.md).
